# CLI 与安装

- **职责**：`bin/ai-harness` 负责初始化、老项目接入、冲突隔离、候选目录扫描、体检，以及向 Codex/Claude Code 安装指向共享技能的薄入口。
- **边界**：目标项目的模块边界、公共契约和红线必须基于证据确认；目录扫描只给候选。技能安装只更新宿主、来源均匹配的管理目录，复制或写入失败须报错；Git 归属识别覆盖 `.git` 目录、worktree 的 `.git` 文件和父仓库子目录，归属无法判定时中止，不新建嵌套仓库。
- **入口**：`bash bin/ai-harness help`；分发模板来自 `template/`。
- **不做升级与迁移**：没有 `upgrade` 命令，也没有 manifest 基线。升级、降级与跨版本布局变化写在 `retrofit-legacy.md`，由项目 AI 比对模板手动完成。2.0 曾有约 360 行升级与 270 行迁移代码，因越写越臃肿删除（维护者 2026-10-25 决定）。
- **验证**：语法检查、`retrofit --dry-run` 只读冒烟、`tests/cli-smoke.sh`（init 可用、retrofit 不覆盖已有文件）、临时技能目录安装正反例和 Git 归属样本。
