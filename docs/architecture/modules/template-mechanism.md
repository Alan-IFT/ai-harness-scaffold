# 模板机制

- **范围**：`template/scripts/`、`template/harness/`、`template/process/specs/_templates/`。根目录 `scripts/` 只转发。
- **为什么门只查骗不过的信号**：字段已填、命令跑过、状态指纹一致这类检查不会误报；措辞与方案质量交给独立审查和人（ADR-0003）。
- **为什么状态指纹全仓计算、只排除 `process/`**：按文件清单的局部指纹依赖人工确认依赖，容易漏；流程记录集中在一个目录，排除一处即可。
- **为什么任务池用目录锁**：`archive` 与 `start-next` 可能被两个会话同时调用，锁保证只有一个活跃 Spec 被创建。
- **为什么验证只认 `verify.conf` 的一条命令**：自动探测工具链在老项目里经常选错；由接入时的 AI 选一条真实命令更可靠。
- **locale**：宿主 shell 可能没有 UTF-8 locale。多字节字符不放进 `[]` 字符类；全角冒号与全角空格在取字段值前归一，自检用 `LC_ALL=C` 复跑。
