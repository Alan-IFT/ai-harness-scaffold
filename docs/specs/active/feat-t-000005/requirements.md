## 1. 业务背景与目标 (Context & Goal)
- **背景**：博客实践表明同一上下文写方案再自审容易放水；「适当、尽量」类 AC 会被 AI「做」通过；记忆只增不纠会出现多个当前答案；AI 不检索已有实现会抬高重复代码。脚手架已具备大部分机制，这四处仍是空白。
- **完成后的行动与效果**：目标项目的 Agent 在任意宿主中断后续做时，按同一份项目文件执行这些规则；后续 Spec 的 G2 报错次数、设计审查记录与复用检索行可在归档 Spec 中回访观察。
- **Non-Goals（本次明确不做）**：
  - 不做 Claude Code / Codex 专属 hook、权限配置或知识命中埋点。
  - 不改 `harness/redlines.conf`，不为独立设计审查和复用检索新增 G3 强制校验。
