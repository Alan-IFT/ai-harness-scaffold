# Skill: 记忆与规则清理

**使用时机**：`scripts/ai-check-bloat.sh` 报警，或觉得 `MEMORY.md`、`AGENTS.md` 在变长时。

1. **删过期**：逐条看 `MEMORY.md`。与代码冲突的以代码为准改写或删除；验证不了、只描述“当时发生了什么”、只记代码事实（「X 定义在 Y」）的删除。
2. **合并**：同一主题只留与当前代码一致的一条，追溯交给 Git。
3. **移走**：已成为某模块稳定约定的，写进 `docs/architecture/modules/<module>.md` 后删除原条目。
4. **写成检查**：能由 lint、类型或测试拦住的，写成检查后从文档里删掉。
5. **做减法**：`AGENTS.md`、指南和模板只减不增；一直没用上的规则或指南删除。新增常驻规则只写成建议，交维护者决定。
6. 再跑 `bash scripts/ai-check-bloat.sh`，提交。
