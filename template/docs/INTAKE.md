# 历史需求入口与处理决定

新需求直接告诉 AI，由 AI 用任务池的 `intake` 收进 `docs/task-pool/`；本文件保留旧格式的历史记录，不再新增任务。任务原话、补充、旧优先级信息与稳定 Spec ID 由单个任务文件保存。

> 旧版项目的 R-ID 记录可继续在此查阅；新需求使用任务池中的 T-ID。不要把同一需求再抄到本表。

| ID | 提出时间 / 来源 | 原始问题或原话 | 期望结果与证据 | 一次处理决定与理由 | 关联 Spec ID |
| :-- | :-- | :-- | :-- | :-- | :-- |

历史条目仍保留稳定 Spec ID；用 `bash scripts/ai-gate.sh status <feat-id>` 查阶段。产品价值、优先级和是否投入由人判断；AI 可整理选项与证据。
